Store secrets in a file?

{% if let Some(e) = error %}
{{ e }}
{% endif %}

KarbonFM will keep your passwords and API keys in a file, secrets.toml, in its data folder. Only your user account can read or write the file.

This is less protected than a keychain. The file is not encrypted: any program running as your user can read it.

The file is never put in a backup, and restoring a backup keeps it. When a system keychain is running, you can move the secrets there from Settings.

The safer choice is to install GNOME Keyring or KWallet and restart KarbonFM.
