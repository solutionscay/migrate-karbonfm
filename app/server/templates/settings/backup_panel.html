A backup is a folder with a copy of the database, the attached files and a list of what is in it. It is made while you work; nothing has to be closed.

Passwords and API keys are not in a backup: they stay on this computer, in its keychain (or KarbonFM's secrets file), and a restore keeps them. After restoring on another computer, type them again above.

Restoring replaces all the data in KarbonFM with the backup's. A copy of the current data is kept first, in the app's data folder.
