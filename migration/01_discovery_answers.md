### Caveats from Step 3 (for the Step 6 audit)

- The graph rows (both panes) were built from parsed digests, with raw files sampled, not read object by object. The layout rows of panes 02 and 03 were read through condensed views and rule maps. The audit should spot-check them.
- Script panes shared a temp folder and one overwrote another's `callers.json`, so some `callers` cells may be wrong. Several `none found` signals may therefore have a real caller. Spot-check before dropping (D-11).
- Signal grouping is mechanical: each signal goes to the first question whose keyword rule matches its text, and every signal from a tooling file goes to D-01. A signal can touch more than one question; the TSV names the one whose answer settles it.
