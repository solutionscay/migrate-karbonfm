  Calculation:
    | /*#######################################################
    | 
    | PURPOSE : 
    | 	Formats and validates the JSON string that is passed in
    | 
    | PARMS:
    | 	json -  the JSON String
    | 
    | RETURNS
    | 	When valid: Formated JSON
    | 	When invalid : Error JSON

    | #######################################################*/
    | 
    | Let(
    | [
    | 
    |

    | valid = ( Left(validated;1) <> "?" )
    | ];

    | 	valid ; validated ;
    | 
    |

    | 		JSON.Error.Validation ( descriptor  ; json ) ;

    | 	)
    | )
    | )
