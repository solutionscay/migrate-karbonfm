   5    #@description
        
        This script queries the Commander script located in each file to retrieve the version from the meta table in each file. Commander was originally designed to be used with an FMP URL call to avoid dependencies, however in this case we do want dependencies so the files open with the credentials that opened this file. 
        
        Since we envision this script being used to retrieve file versions from other servers, we created the external data sources to support variable file paths. With this approach you could, for instance, query a production server for its versions and compare them to the dev files in order to build a migration template for just the files that have changed.
