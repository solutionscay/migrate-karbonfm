    | We're following a form of Semantic Versioning (aka SemVer) to track file and application versions in Karbon. Sequence of three digits maps to: Major.Minor.Patch (e.g., 1.0.1)
    |

    |  - All other non-breaking changes increment the patch number (lowest risk)
