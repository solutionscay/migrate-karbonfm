# S-05: Tailwind/DaisyUI build without Node

Risk R-08 (02). Run 2026-10-30 on branch `spike/s01-s05`. Result: **passes on macOS; Windows and Linux wait for CI.**

## What was built

- `app/styles/app.css` is the Tailwind source: `@import "tailwindcss"`, `@plugin "./vendor/daisyui.mjs" { themes: false; }`,
  the Geist `@font-face` rules, then `karbon.css` (a copy of `design/assets/app.css`: the karbon-light and karbon-dark
  themes and the app shell) and the print rules.
- `app/tools/build-css.sh` downloads the Tailwind **standalone CLI 4.1.11** for the host into `app/tools/bin/` (ignored by
  git), checks its SHA-256 against the release's `sha256sums.txt` (pinned in the script for macOS arm64/x64, Linux
  x64/arm64 and Windows x64), and builds `app/server/assets/app.css` (minified, about 50 KB).
- The DaisyUI plugin is **DaisyUI 5.0.43**, vendored as `app/styles/vendor/daisyui.mjs` and `daisyui-theme.mjs` from the
  DaisyUI GitHub release. The standalone CLI loads the `.mjs` plugin itself; no Node, no npm, no `node_modules`.
- The built CSS is committed. `cargo build` only embeds it (`include_bytes!`), so a Rust build needs no CSS tool and no
  network. CI rebuilds it on every platform and fails if the result differs from the committed file.
- htmx 2.0.4, Alpine.js 3.14.8, Chart.js 4.4.7 and the Geist / Geist Mono variable fonts (geist 1.5.1, OFL) are vendored
  in `app/server/assets/vendor/` with the version in the file name, and embedded in the binary. These are the versions
  design/ uses.

## Findings

- No plan change: the standalone CLI and the DaisyUI plugin file are enough (02, "UI stack").
- Keep the generated CSS committed and checked in CI, instead of building it in `build.rs`: the Rust build stays
  offline and does not depend on a 100 MB binary download.
- Tailwind must see every class: the source scans `server/templates` and `server/assets/app.js`. A class that is only
  built in Rust strings would be missed; keep class names in templates.
- The CLI prints the DaisyUI banner to stdout, not into the minified CSS; do not test for it.
